# Proposal

## Why

Креды Физикла (`LOGIN`/`PASSWORD`) лежат в `.env` у корня проекта — месте, известном только этому репозиторию и запуску из терминала. Стандартный паттерн MCP-серверов (GitHub MCP и др.) — получать секреты через `env`-блок конфига клиента, который запускает процесс: тогда «как запускать» и «с какими секретами» описаны в одном месте, а `.env`-лоадер (`loadEnvFile`, два пути поиска файла) не нужен вовсе.

## What Changes

- Креды читаются только из переменных окружения процесса (`LOGIN`, `PASSWORD`), которые задаёт MCP-клиент в `env`-блоке своей конфигурации.
- Удалены `loadEnvFile()` и файл `.env`; smoke-прогон запускается с inline-env: `LOGIN=… PASSWORD=… npm run smoke`.
- **BREAKING**: workspace-конфиг `.zcode/config.json` (в нём была только запись `fizikl`) удаляется из репозитория. Подключение в ZCode — через юзер-скоуп `~/.zcode/cli/config.json` с полной записью (command + args + env): юзер-скоуп заменяет workspace-запись целиком, послойного слияния полей нет.
- Тексты ошибок о входе переписаны с «в `.env`» на «в `env`-блоке конфига MCP-клиента» (`src/config.ts`, `src/fizikl/auth.ts`).
- README: секции установки и подключения переписаны под `env`-блоки всех клиентов (ZCode юзер-скоуп, Claude Desktop, Cursor, Claude Code); строка `.env` уходит из `.gitignore`.
- Новый ADR-0007 фиксирует решение; ADR-0003/0006 не правим задним числом.
- Fail-fast при старте без кредов сохраняется (меняется только текст).

## Capabilities

### New Capabilities

- `server-configuration`: откуда сервер берёт креды и как клиенты его запускают — только переменные окружения из `env`-блока клиентского конфига, единый паттерн «персональный конфиг клиента» для всех клиентов, fail-fast со русскоязычной подсказкой при отсутствии кредов.

### Modified Capabilities

— (главные спеки проекта пусты, существующих требований не меняем)

## Impact

- **Код**: `src/config.ts` (удаление `loadEnvFile`, новый текст ошибки), `src/index.ts` (убрать вызов лоадера), `src/fizikl/auth.ts` (текст ошибки логина), `src/smoke.ts` (убрать лоадер, обновить док-комментарий и шаг «Креды из .env»).
- **Конфиги**: `git rm .zcode/config.json`; вне репозитория — добавить запись `fizikl` с `env` в `~/.zcode/cli/config.json` (на машине пользователя, в скоупе задач по установке).
- **Тесты**: `tests/unit/auth.test.ts` матчит текст ошибки по `/LOGIN и PASSWORD/` — новые тексты должны сохранять эти слова.
- **Доки**: README, `docs/adr/0007-*.md`; `docs/research/*.md` — исторические заметки, не трогаем.
- **Сборка**: пересборка `dist/` (`npm run build`) после правок кода.
