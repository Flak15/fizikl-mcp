# 0005. Дефолты: eaten_date = сегодня, meal по времени суток

Дата: 2026-10-31
Статус: принято

## Контекст

`eaten_date` — календарная дата без времени; приём пищи выбирается slug'ом. Требовать оба поля от LLM в каждом вызове — шум; угадывать приём пищи по времени — риск, но пользователь явно попросил.

## Решение

- `eaten_date` опционален → сегодня. Дата и время — по локальной таймзоне машины, где запущен сервер (при stdio-использовании это машина пользователя); отдельной конфигурации таймзоны нет.
- `meal` опционален → по локальному времени машины сервера, полуинтервалы:
  - [04:00, 12:00) → `zavtrak`
  - [12:00, 18:00) → `obed`
  - [18:00, 21:00) → `uzhin`
  - [21:00, 04:00) → `perekus` (включая 00:00–04:00)
- Явно переданный `meal` перекрывает автоподбор.
- Выбранный дефолт всегда виден в ответе инструмента (не молча).

## Последствия

- Интервал 21:00–04:00 непрерывен через полночь: и поздняя еда, и еда до 4 утра — `perekus`, при неуказанной дате записывается «сегодня».
- Автоподбор по времени может ошибаться против привычек конкретного человека — явный `meal` всегда доступен.
