# 0002. Транспорт: stdio (локальное использование)

Дата: 2026-10-31 (пересмотрено в тот же день; заменяет первую версию «Streamable HTTP»)
Статус: принято (пересмотрено)

## Контекст

Первоначально предполагалось удалённое использование сервера, и первой версией этого ADR был выбран Streamable HTTP. Пользователь уточнил: сервер будет использоваться **локально** — клиент сам запускает процесс рядом с собой. Причина для сетевого транспорта отпала.

## Решение

**stdio-транспорт** (`StdioServerTransport` из MCP SDK). Клиент (ZCode / Claude Desktop / Cursor) запускает процесс сервера командой из своей конфигурации (сниппет — в README). Ни порта, ни сети, ни отдельной авторизации endpoint'а.

## Последствия

- Отдельная авторизация самого MCP-сервера не нужна: доступ к процессу = доступ к машине пользователя; креды Физикла читаются из `.env`.
- Все логи сервера — только в stderr (stdio занят протоколом).
- Если позже появится удалённый сценарий — транспорт добавится рядом, не вместо.
