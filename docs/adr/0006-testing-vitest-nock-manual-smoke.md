# 0006. Тестирование: vitest + undici MockAgent, ручной smoke на прод

Дата: 2026-10-31 (поправлено в тот же день при реализации: nock → undici MockAgent)
Статус: принято

## Контекст

ADR-0001 отложил выбор тестового фреймворка в npm-экосистему. API Физикла — внешняя сеть, привязанная к реальному аккаунту; автотесты не должны писать в настоящий дневник питания.

## Решение

- **Юнит-тесты: vitest + undici MockAgent** (моки HTTP на уровне диспетчера fetch). Покрывают: auth-флоу (ленивый логин, refresh по 401, полный ре-логин, смерть refresh), дефолты даты/приёма пищи (окна 04–12/12–18/18–21/21–04), каждый инструмент.
  - Поправка к первоначальной формулировке: вместо nock — undici `MockAgent` c `setGlobalDispatcher`. nock не видит нативный `fetch` (undici не ходит через `node:http`), а `MockAgent` перехватывает его на уровне глобального диспетчера — проверено на Node 24.
- **Smoke-скрипт `npm run smoke`** — ручной, не в CI: реальный цикл на проде с кредами из `.env` — логин → поиск → карточка → запись → проверка списка за дату → удаление (как в `docs/research/pht-api.md`).

## Последствия

- Автотесты безопасны для аккаунта и повторяемы.
- Smoke пишет в настоящий дневник и удаляет запись за собой; автоматический дневной отчёт за дату прогона может сохранить значения дня теста.
