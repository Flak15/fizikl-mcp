# 0003. Авторизация Физикла: JWT-пара с персистенцией refresh-токена

Дата: 2026-10-31
Статус: принято

## Контекст

Вход Физикла: `POST https://pht.space/jwt-auth/api/token/` с email+паролем → `access` (3 ч) + `refresh` (30 д). Микросервисы требуют нестандартный заголовок `Authorization: Secret <access>`. Креды лежат в `.env` (`LOGIN`, `PASSWORD`).

## Решение

- Логин лениво, при первом запросе инструмента.
- Refresh-токен персистим в `~/.fizikl-mcp/auth.json` (вне репозитория) → ре-логин раз в ~30 дней.
- Access держим в памяти; при 401 — refresh; если refresh умер — полный ре-логин; если и он не помог — русскоязычная ошибка наверх.
- Прод-URL'ы (`pht.space`, `food-tracker.pht.space`, `search.pht.space`) зашиты константами, переключателя контуров нет.

## Последствия

- `.env` не должен попасть в git (`.gitignore` до первого коммита).
- `~/.fizikl-mcp/auth.json` содержит живой refresh-токен — файл с правами 600.
