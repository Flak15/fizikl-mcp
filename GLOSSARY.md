# Глоссарий

Термины проекта fizikl-mcp. Использовать как здесь, синонимы не вводить.

- **Физикл (Physical Life)** — мобильное приложение дневника питания; бэкенд — микросервисы на `*.pht.space`. Исследование API: `docs/research/pht-api.md`.
- **JWT-пара** — `access` (живёт 3 ч) и `refresh` (30 д) токены входа. Выдача: `POST https://pht.space/jwt-auth/api/token/` с `{username: <email>, password: <пароль>}`. Обновление access: `/jwt-auth/api/token/refresh/`.
- **Secret-схема** — нестандартная авторизация к микросервисам Физикла: заголовок `Authorization: Secret <access>` (не `Bearer`).
- **food-tracker** — `food-tracker.pht.space` (Django + DRF): дневник питания — приёмы пищи, съеденное, отчёты, база продуктов. Главный сервис для MCP.
- **search** — `search.pht.space` (FastAPI): поиск продуктов; возвращает только список ID продуктов.
- **Продукт (food)** — карточка продукта: КБЖУ, витамины/минералы, список порций `food_servings`, `cooking_coefficient`.
- **Порция (serving)** — единица измерения продукта: `id`, `name` («г», «порция», «oz»…), `metric_weight` (вес одной порции в граммах). Порция «г» с `metric_weight: 1` — способ записать «просто граммы».
- **serving_amount** — количество порций в записи (= граммы, если выбрана порция «г»).
- **Приём пищи (meal)** — завтрак / обед / ужин / перекус; идентифицируется slug'ом: `zavtrak | obed | uzhin | perekus`.
- **Запись о съеденном (eaten-food)** — строка дневника: `serving` + `serving_amount` + `meal` + `eaten_date`.
- **eaten_date** — календарная дата `YYYY-MM-DD` без времени.
- **Итог дня (day report)** — дневные КБЖУ и вес съеденного; `GET /api/v1/report/list/calendar/`.
- **Тонкая обёртка (thin wrapper)** — принцип дизайна инструментов: один инструмент ≈ один шаг API, сервер не ищет и не матчит продукты сам. Единственное исключение — батчинг выдачи: `search_food` докупает карточки топ-N.
- **MCP-сервер (этот проект)** — локальный stdio-процесс, тонкие обёртки над API Физикла для LLM-клиентов.
