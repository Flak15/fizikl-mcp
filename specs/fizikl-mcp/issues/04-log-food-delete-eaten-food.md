# 04: Запись: `log_food` с дефолтами + `delete_eaten_food`

**What to build:** Путь записи в дневник: `log_food(serving_id, serving_amount, meal?, eaten_date?)` создаёт съеденное (массив из одного элемента в `create-list`), `delete_eaten_food(id)` удаляет запись. Дефолты: `eaten_date` → сегодня по локальной таймзоне машины; `meal` → по локальному времени окнами [04:00,12:00) `zavtrak`, [12:00,18:00) `obed`, [18:00,21:00) `uzhin`, [21:00,04:00) `perekus`; явный аргумент перекрывает автоподбор; применённый дефолт всегда виден в ответе. Демо serving_id можно взять из `docs/research/pht-api.md`.

**Blocked by:** 01 (Каркас MCP-сервера + авторизация Физикла + `list_meals`)

**Status:** ready-for-agent

- [ ] Запись «200 г гречки в обед» создаётся (порция-«г», `serving_amount: 200`, `meal: "obed"`) и появляется в списке за дату
- [ ] Без `eaten_date` запись уходит на сегодня (локальная таймзона машины), без `meal` — по окнам времени; оба дефолта названы в ответе
- [ ] Окна времени: 04:00–12:00 завтрак, 12:00–18:00 обед, 18:00–21:00 ужин, 21:00–04:00 (через полночь) перекус
- [ ] Явно переданный `meal`/`eaten_date` перекрывает автоподбор
- [ ] `serving_amount < 0.01` или неизвестный slug приёма — русскоязывая ошибка, ничего не записано
- [ ] `delete_eaten_food(id)` удаляет запись (204), повторное удаление — понятная ошибка
- [ ] Юнит-тесты окон времени и дефолтов (фиксированное «сейчас»), моки на запись/удаление
