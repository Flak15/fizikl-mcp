# 02: Подключить сервер в текущий агент (ZCode)

**What to build:** Зарегистрировать собранный сервер в конфигурации MCP текущего агента (ZCode, workspace scope), чтобы инструменты Физикла стали доступны в сессиях агента как `mcp__fizikl__*`. Убедиться, что сервер подхватывается, подключается и его инструменты видны.

**Blocked by:** 01 (Каркас MCP-сервера + авторизация Физикла + `list_meals`)

**Status:** done

- [x] Конфигурация MCP ZCode (workspace scope) содержит сервер fizikl с командой запуска собранного `dist/`
- [x] После перезагрузки конфигурации сервер отображается подключённым, без ошибок в статусе
- [x] Инструмент `list_meals` виден среди инструментов агента и при вызове возвращает приёмы пищи
- [x] В README отмечено, как подключить сервер в ZCode / Claude Desktop / Cursor

## Comments

- Конфиг зарегистрирован в `.zcode/config.json` (workspace scope, формат `mcp.servers` — `mcp__fizikl__*`). Абсолютный путь до `dist/index.js` — машина-специфичный, при переносе репозитория поправить.
- Подключение проверено на уровне протокола: SDK-клиент по stdio запустил собранный `dist/index.js` — connect ок, `list_meals` виден, вызов вернул 4 приёма пищи без ошибки; авторизация по `.env` работает. (Это не «smoke» из ADR-0006 — тот полный цикл появится в тикете 06.)
- Статус в самом клиенте ZCode подтвердить в новой сессии после перезагрузки конфигурации (Settings → MCP, сервер `fizikl` без ошибок): workspace-серверы подключаются автоматически, но список инструментов текущей сессии фиксируется при её старте.
- В README исправлен ZCode-сниппет: раньше указывал несуществующий `.zcode/mcp.json` с корневым `mcpServers`; правильный файл — `.zcode/config.json` с вложенностью `mcp.servers`.
